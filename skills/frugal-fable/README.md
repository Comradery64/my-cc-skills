# Frugal Fable

Run Fable (or premium models) efficiently: **default effort to `low`, escalate only on signals; delegate work to cheaper models per task complexity**.

Perfect for token-heavy work: features, multi-file changes, research, testing, debugging.

**⚠️ Turn Ultracode off before using** (toggle by model selector).
